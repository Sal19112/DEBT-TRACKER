Google Sheets Integration

This dashboard reads from and writes to your Google Sheet. Follow these steps to connect it.

1
Deploy a Google Apps Script Web App — Open your Google Sheet → Extensions → Apps Script → paste the script below → Deploy as Web App (Anyone can access).
2
Copy the Web App URL from the deployment dialog and paste it here.
3
Sheet format: Column A = Lender, B = Type, C = Total, D = Remaining (formula). From column F onward each payment column has a date in row 1 and the payment amount in the row.
